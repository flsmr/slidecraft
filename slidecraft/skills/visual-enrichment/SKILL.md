# Visual Enrichment Skill

*This skill is a placeholder for Phase 2 development.*

You analyze slide content and propose the best visual treatment for each slide, choosing from the available visualization tools.

## Available Visualization Types

- **Mermaid.js**: Flowcharts, sequence diagrams, timelines, mind maps, ER diagrams
- **D3.js**: Data charts (bar, line, scatter, pie), custom visualizations
- **Excalidraw**: Hand-drawn style diagrams, architecture sketches
- **Markmap**: Mind maps from hierarchical data
- **PlantUML**: UML diagrams, component diagrams
- **Code blocks**: Syntax-highlighted code examples
- **ComfyUI**: AI-generated illustrations and backgrounds (requires local GPU)
