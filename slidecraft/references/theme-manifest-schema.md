# Theme Manifest Schema v2.0

Generated by `slidecraft/scripts/extract-pptx-theme.py`.
Read by: `validate-theme.py` (with v1 compat shim), T-05 layout generator, T-06 deck generator.

## Top-level structure

```json
{
  "schema_version": "2.0",
  "source_pptx": "template.pptx",
  "slide": {
    "width_emu": 12192000,
    "height_emu": 6858000,
    "ref_px": [1920, 1080]
  },
  "theme": {
    "colors": { "dk1": "#1D1D1F", "accent2": "#55FF4D", ... },
    "fonts":  { "major_latin": "Source Sans Pro Bold", "minor_latin": "Source Sans Pro" }
  },
  "master_background": { "type": "solid", "color": "#FFFFFF" },
  "layouts": [ ... ],
  "images": [ ... ],
  "layout_count": 45
}
```

## `slide`

| Field | Type | Description |
|-------|------|-------------|
| `width_emu` | int | Slide width in EMU (914 400 / inch) |
| `height_emu` | int | Slide height in EMU |
| `ref_px` | [int, int] | Reference render resolution `[1920, 1080]` |

## `theme.colors`

Object with 12 standard Office color slot names as keys (`dk1`, `lt1`, `dk2`, `lt2`,
`accent1`–`accent6`, `hlink`, `folHlink`). Values are always concrete `#RRGGBB` strings;
`schemeClr` references are resolved at extraction time.

## `theme.fonts`

| Field | Description |
|-------|-------------|
| `major_latin` | Heading font family (OOXML `majorFont/latin`) |
| `minor_latin` | Body font family (OOXML `minorFont/latin`) |

Note: `+mj-lt` and `+mn-lt` references in shape XML are resolved to these names.

## `master_background`

A fill object (see Fill below) or `null` if the master has no explicit fill.

## `layouts[]`

Each element:

```json
{
  "name": "1_Titel Schwarz | mittel",
  "slug": "l-1-titel-schwarz-mittel",
  "background": { "type": "solid", "color": "#1D1D1F" },
  "shapes": [ ... ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | PPTX layout name (may contain German/Unicode characters) |
| `slug` | string | URL-safe slug derived from name |
| `background` | Fill or null | Layout background fill |
| `shapes` | Shape[] | All shapes in document (z) order |

## `shapes[]`

Each shape in the `shapes` array:

```json
{
  "name": "Textplatzhalter 14",
  "kind": "placeholder",
  "z": 1,
  "ph_idx": 19,
  "ph_type": "body",
  "geometry": "custGeom",
  "custGeom_path": "M 0 400006 C 3175 173254 ...",
  "custGeom_viewBox": [10481728, 1674234],
  "bbox": {
    "left_pct": 22.31, "top_pct": 22.36, "width_pct": 21.39, "height_pct": 6.07,
    "left_px": 428.4, "top_px": 241.5, "width_px": 410.7, "height_px": 65.6
  },
  "rotation_deg": -4.0,
  "fill": { "type": "solid", "color": "#FFFFFF" },
  "border": null,
  "text_default": {
    "value": "Example",
    "font_pt": 12.2,
    "weight": 700,
    "italic": false,
    "family": "Source Sans Pro Bold",
    "color": null,
    "align_h": null,
    "align_v": null,
    "wrap": null,
    "autofit": null
  }
}
```

### Shape fields

| Field | Type | Values | Description |
|-------|------|--------|-------------|
| `name` | string | | PPTX shape name |
| `kind` | string | `shape`, `placeholder`, `picture`, `group` | Shape type |
| `z` | int | 0+ | Z-order index (document order) |
| `ph_idx` | int | | Placeholder index (only if `kind == "placeholder"`) |
| `ph_type` | string | `title`, `centeredTitle`, `body`, `object`, etc. | Placeholder type |
| `geometry` | string | `prstGeom:<name>`, `custGeom`, `none` | Geometry type |
| `custGeom_path` | string | SVG path data | Only if `geometry == "custGeom"` |
| `custGeom_viewBox` | [int, int] | `[w, h]` | Path coordinate space |
| `bbox` | Bbox | | Bounding box in both pct and px |
| `rotation_deg` | float | | Rotation in degrees (negative = counter-clockwise in PowerPoint) |
| `fill` | Fill or null | | Shape background fill |
| `border` | Border or null | | Shape stroke/border |
| `text_default` | TextDefault or null | | Effective text properties (cascade-resolved) |

### Bbox

```json
{
  "left_pct": 22.31, "top_pct": 22.36, "width_pct": 21.39, "height_pct": 6.07,
  "left_px": 428.4,  "top_px": 241.5,  "width_px": 410.7,  "height_px": 65.6
}
```

`*_pct` values are percentages of slide width/height.
`*_px` values are pixels at the 1920x1080 reference resolution.

### Fill

```json
{ "type": "solid", "color": "#RRGGBB" }
```

or gradient:

```json
{
  "type": "gradient",
  "stops": [
    { "pos": 0.0, "color": "#RRGGBB" },
    { "pos": 100.0, "color": "#RRGGBB" }
  ],
  "angle": 90.0
}
```

`null` means no fill (transparent).

### Border

```json
{ "color": "#FFFFFF", "width_pt": 11.0 }
```

`null` means no border.

### TextDefault

Cascade-resolved effective text properties. Uses cascade order:
1. First run `<a:rPr>` in shape txBody
2. First paragraph `<a:pPr>` + `defRPr`
3. Shape `lstStyle/lvl1pPr/defRPr`
4. Matching layout placeholder `lstStyle/lvl1pPr/defRPr`
5. Master `txStyles/titleStyle` | `bodyStyle` | `otherStyle` `lvl1pPr/defRPr`

| Field | Type | Description |
|-------|------|-------------|
| `value` | string | Default text from first paragraph run |
| `font_pt` | float or null | Font size in points |
| `weight` | int or null | `400` (normal) or `700` (bold) |
| `italic` | bool or null | |
| `family` | string or null | Resolved font family name (`+mj-lt`/`+mn-lt` expanded) |
| `color` | string or null | `#RRGGBB` |
| `align_h` | string or null | `"left"`, `"center"`, `"right"`, `"justify"` |
| `align_v` | string or null | `"t"`, `"ctr"`, `"b"` (from `bodyPr anchor`) |
| `wrap` | string or null | `"none"` or `"square"` (from `bodyPr wrap`) |
| `autofit` | string or null | `"noAutofit"`, `"spAutoFit"`, `"normAutofit"` |

## `images[]`

Assets extracted to `public/assets/`. Each entry:

```json
{
  "filename": "master0_Logo_3.png",
  "source": "master0",
  "shape_name": "Logo 3",
  "content_type": "image/png",
  "size_bytes": 12345,
  "left_emu": 0, "top_emu": 0, "width_emu": 914400, "height_emu": 914400
}
```

## Compatibility notes

### v1 → v2 breaking changes

- `schema_version` changed from `"1.0"` to `"2.0"`
- `slide_dimensions` dict replaced by `slide` dict with `ref_px`
- `theme.colors` and `theme.fonts` now nested under `theme` (was top-level)
- `layouts[].placeholders[]` array replaced by unified `layouts[].shapes[]`
- `layouts[].image_shapes[]` merged into `shapes[]` with `kind: "picture"`
- `backgrounds` dict removed — each layout now has `background` inline

### validate-theme.py compatibility shim (T-05 target)

`validate-theme.py` still reads `pptx-reference-manifest.json` (a separate
manifest file, not `theme-manifest.json`). That file uses a different
format (`vue_layout`, `placeholder` keys). No changes needed to the validator
until T-05 regenerates layouts that consume v2 directly.

If you need the validator to also read `theme-manifest.json` as a reference
manifest, add a small shim in `_generate_aligned_slides_md()` that detects
`schema_version == "2.0"` and converts layouts to the expected
`[{vue_layout, placeholder}]` format. This shim should be labelled:
`# TODO T-05: remove v1 compatibility shim`.
