# Presentation Design Best Practices — Quick Reference

This document provides the core rules that all slidecraft skills and agents reference when evaluating or generating slide content.

## Information Density
- Maximum 40 words per slide (academic), 25 words (keynote)
- Maximum 4 bullets per slide, 7 words per bullet
- One main message per slide

## Typography
- Body text: minimum 24pt (live), 18pt (virtual)
- Headlines: minimum 30pt
- Maximum 2-3 typefaces per deck
- Line height: 1.5x-1.7x font size for body

## Color
- 60-30-10 rule: dominant / secondary / accent
- Maximum 5-7 unique colors per deck
- WCAG AA contrast: 4.5:1 normal text, 3:1 large text
- Never use color alone to convey meaning

## Slide-to-Time Ratios
- Keynote/TED: 1-2 slides/min
- Business: 0.5-1 slides/min
- Academic: 0.5-0.67 slides/min
- Technical: 0.33-0.5 slides/min

## Assertion-Evidence Design
- Headline: one full sentence stating the key assertion (not a topic label)
- Body: visual evidence (chart, diagram, image)
- Bad: "Solar Panel Efficiency" → Good: "Solar panel efficiency increased 40% since 2015"

## Anti-Patterns (Auto-Fail)
- Wall of text (>60 words)
- Bullet point overload (>6 bullets)
- Font too small (<18pt)
- No contrast (ratio <3:1)
- Rainbow palette (>7 colors on one slide)
- >5 consecutive same-layout slides
