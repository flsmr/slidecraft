# Start New Presentation

*This command is a placeholder for Phase 2 development.*

## Steps

1. **Choose workspace location**: Ask where to create the presentation project.
2. **Scaffold workspace**: Create the standard directory structure with `.slide-creator.json`, `input/`, `theme/`, `slides/`, `export/`.
3. **Briefing interview**: Gather requirements (audience, duration, tone, template).
4. **Accept raw material**: Have the user upload/point to their source material.
5. **Hand off to authoring skill**: Begin the content pipeline.
